# Secret Sharing

A desktop app for Shamir's Secret Sharing, built with Nuxt 4 and Tauri 2. All cryptographic operations run in the Rust backend — no crypto in the browser.

Licensed under the [MIT License](./LICENSE).

Look at the [Nuxt 3](https://nuxt.com/docs/getting-started/introduction) or [Tauri 2](https://beta.tauri.app/guides) documentation to learn more.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for development setup, coding conventions, pull request workflow, and the release process.

## Setup

Make sure to install the dependencies:

```bash
npm install
```

## Development

```bash
npm run tauri dev
```
